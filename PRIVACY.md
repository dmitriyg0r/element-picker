# Element Picker privacy policy

## What Element Picker uses

When you select an element, Element Picker can read its visible text, the heading of its surrounding block, and DOM details such as its tag, CSS selector, and selected attributes. When you select a region, it records the area's coordinates and dimensions. The extension associates notes with the current page path and may include the parameters `id`, `itemtype`, `forcetab`, or `_itemtype`. It skips the values of input fields.

Element Picker uses this information and the text you enter to display your notes and include context in the text you copy.

## Where data is stored

Notes and their page context stay in memory in the current document. They are cleared when you reload or close the page. Shortcut settings are stored in Chrome's local extension storage.

When you choose **Copy**, the extension writes the notes to your clipboard. You control which app or service receives that text if you paste it. Element Picker has no analytics and does not send notes, website content, or settings to a developer server or third party.

## Contact

For privacy questions, contact the developer through the [project's GitHub repository](https://github.com/dmitriyg0r/element-picker). Please avoid including private page contents in public issues.
